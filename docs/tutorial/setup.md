PPDS is supposed to be a ModuleScript which you can place inside your Roblox game's *ServerScriptService* or wherever else is preferred. PPDS can only be used server-side

### Option #1: Get PPDS from the Roblox library
   - Get the library model [here](https://www.roblox.com/library/95562270661505/)
   - Move "PaoPaoDataStore" ModuleScript to ServerScriptService or wherever.

* [PaoPaoDataStore repository](https://github.com/Paopun20/PaoPaoDataStore)
